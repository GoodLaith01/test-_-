# sunset-beach

A Claude Code desktop theme (a "mod"): warm sunset colors in light and dark mode, rolling waves, drifting seagulls, and fireworks when a pull request is merged.

## Install

Copy this folder to `~/.claude/skills/sunset-beach/`. It loads at the start of the next session in the Claude Code desktop app.

- `/sunset-fireworks` previews the merge fireworks.
- Only one mod can set a theme at a time.
